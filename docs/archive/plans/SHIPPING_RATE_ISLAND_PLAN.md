## 1. 数据模型（先摸清才能设计）

源文件：`ae5a7f6345c82d53575081d63e91b90a.xlsx`（21 个 sheet，默认取「无忧物流-标准」，可切换到其中 **19 张** —— 覆盖率见 §2.1）。

### 1.1 这张表不是二维表，是 **17 张价卡拼在一张 sheet 上**

- 268 行 × 40 列；**17 个分节**，每节 = 3 行表头 + N 行国家数据
- 分节之间列结构**互不相同**；全表共 **184 个国家**，且**没有任何国家出现在两个分节**（分节是互斥的目的地分组）

| 分节 | 数据行 | 国家数 | 代表国家 |
| ---: | --- | ---: | --- |
| 1 | 16–160 | **144** | 阿尔巴尼亚 … 塞浦路斯（占 78%） |
| 2–7 | 单行 | 各 1 | 俄罗斯 / 乌克兰 / 美国 / 韩国 / 瑞士 / 波兰 |
| 8 | 195–213 | 18 | 奥地利 … 英国 |
| 9–13 | 单行 | 各 1 | 克罗地亚 / 巴西 / 以色列 / 墨西哥 / 智利 |
| 14 | 245–248 | 2 | 马来西亚 / 泰国 |
| 15 | 252–258 | 6 | 捷克 … 葡萄牙 |
| 16 | 262–264 | 2 | 挪威 / 秘鲁 |
| 17 | 268 | 1 | 摩洛哥 |

### 1.2 三种计费类别

| 类别 | 表头字样 | 说明 |
| --- | --- | --- |
| 普货小包 | `小包普货计费` | 无电池 / 非液体化妆品 |
| 非普货小包 | `小包非普货计费` | 含电池 / 非液体化妆品；分节 3 再按 **其他仓 / 香港仓** 分两套 |
| 大包 | `大包计费` / `大包计费（计泡）` | 限重 30kg |

特例：分节 5（韩国）表头是 `小包普货&小包非普货计费` —— 一个价同时适用两类，故价卡类别必须是**集合**而非单值。

### 1.3 两种计价模式

| 模式 | 表头 | 公式 |
| --- | --- | --- |
| `perKg` | `配送服务费 元（RMB）/KG` + `挂号服务费 元（RMB）/包裹` | `费率 × 克重 ÷ 1000 + 挂号费` |
| `firstStep` | `0.5KG首重` + `续重(每500G)` | `首重 + ⌈(克重 − 500) ÷ 500⌉ × 续重`（克重 ≤ 500 时只收首重） |

验算样本（阿尔巴尼亚，普货 0~150g 档）：`209.66 × 100 ÷ 1000 + 18.7 = 39.666` → 39.67 元。

同一国家「大包」可能是两种模式（摩洛哥：0–5000g `perKg`，5000–30000g `firstStep`），故模式是**价卡级**属性。

### 1.4 重量档位

档位写在表头第 2 行（合并单元格），格式不统一：`0~150g(含)` / `0-2100g（含）` / `2100-30000g` / `限重30kg`。有的价卡完全没有档位（如分节 1 大包，只有 `限重30kg`），此时按 `[0, 30000]` 处理。

「无忧物流-标准」表头是三行结构：第 1 行类别名、第 2 行重量档、第 3 行叶子语义。合并单元格只有左上角有值 —— 归一化算法必须"向左回溯找最近的合并源"。

⚠️ **三行只是其中一族**（2026-09-25 实测 21 张 sheet 后修正，见 §2.1）：燕文 / 超级经济 / 4PX / 顺友 大量线路只有 1~2 行表头，且叶子与档位**上下顺序会颠倒**。把行数写死会把这些表整节跳过。

## 2. 归一化算法（把 17 种版式收成一种）

核心思路：**不按固定列号解析，而是按语义扫描**。

```
对每个分节（hdr = A 列 == '运达国家/地区' 的行）：

① 探测本节表头的**行角色**（detectLayout，行号不写死，见 §2.1）
② 扫 leafRow，凡命中叶子语义的列即为「有效列」：
     含「配送服务费」/「重量资费」→ delivery；含「挂号服务费」/「Item 服务费」/「操作处理费」/「处理费」→ register
     含「首重」→ first；含「续重」→ step；含「最低计费重量」/「起重」→ minCharge（列属性，不建卡）
③ 每个有效列向左回溯定位两个「合并源」（**回溯不得越过类别起点**）：
     groupStart → 决定类别 + 变体 + 限重；zoneText → 决定重量档
④ 相邻配对成价卡：delivery+register → perKg 卡；first+step → firstStep 卡
⑤ 数据区起点 = max(leafRow, zoneRow) + 1；逐数据行取数值，构造「国家 → 价卡[]」
⑥ 整节收齐后**再**决定是否采纳：同一目的地在一节内占多行 → 该节是「行式分档表」，整节拒绝
```

### 2.1 表头版式是一族，行角色只能探测

实测源工作簿 21 张 sheet（覆盖率 3/21 → **19/21**）：

| 版式 | 表头行数 | 实例 | 备注 |
| --- | --- | --- | --- |
| 类别 / 档位 / 叶子 | 3 行 | 无忧物流-标准、特惠、优先、三方清关 | 唯一有"类别标题"的一族 |
| 档位 / 叶子（无类别） | 2 行 | 燕文航空挂号小包、超级经济全系列、顺友、威海优选仓 | 类别记 `any` |
| 叶子 / 档位（**上下颠倒**） | 2 行 | 无忧物流-特货标准、特货标快 | 数据起点取 `max(leafRow, zoneRow) + 1` |
| 只有叶子 | 1 行 | 4PX新邮挂号小包、部分超级经济 | 限重写在叶子文本里 |
| 分档行式宽表 | —— | 海运大件专线、超大件专线、优先/特货标准部分分节 | **不支持**（见第 ⑥ 步） |

**六个必须写成守卫的点（否则会静默算错）**：

- **回溯必须被 groupStart 截断**：否则分节 1 大包列会向左回溯到非普货档，大包全算错且不报错。
- **类别判定先剔除「非普货」再找「普货」**：直接 `includes('普货')` 会让 `小包非普货计费` 同时命中两类。
- **档位解析缺失退化为 `[0, 30000]` 而非 `[0, 0]`**：后者让所有大包返回"超出档位"。
- **档位文本里两个相同数字 = 只说上限**（`2KG以内` → `[2g, 2g]` 只覆盖 2 克）；单位须按**整段文本**判 kg/g。
- **本列档位优先于整组限重**：摩洛哥大包两档，组标题「限重30kg」不能盖过档位。
- **叶子同义词必须成套**：`Item 服务费` 就是「挂号服务费」，漏一个等于半张表费用整列丢失。

## 5. 计费口径与边界

- **自动判定**：克重 ≤ 2000g → 普货 → 非普货 → 大包 → `any`；> 2000g → 大包 → 普货 → 非普货 → `any`。`any` **永远排在最后**。
- **手动切换**：普货 / 非普货 / 大包 / 自动 四态；强制某类只用该类 **+ `any` 兜底**，都命中不到 → 明确提示"该重量段无可用运价"。
- **变体**：非普货有 `其他仓` / `香港仓` 两套价（仅乌克兰），默认取无变体价卡，可手动指定。
- **最低计费重量**：报价单单列「最低计费重量 10g」→ 计费克重 = `max(实际克重, 该值)`。
- **币种**：只按人民币计价；表头写 `美元（USD）/KG` 的线路（超级经济 / 无忧物流-特惠）**明确拒算**，不套人民币壳（差 7 倍）。
- **超出档位**：返回"该重量段无可用运价"并给出该国可用档位范围，不返回 0。
- **取整**：默认四舍五入到分，可切"向上取整到分"，两口径只在 `computeFee` 一处实现。
- **不在本方案内**：体积重、单边/合计尺寸大包判定、燃油附加费、汇率来源（见 §8）。

## 6. 守卫（把静默失效钉死）

| 守卫 | 挡什么 |
| --- | --- |
| `normalizeRateSheet` 对真实夹具断言 184 国 / 17 分节 / 两类模式价卡数 | 版式理解错位（最核心） |
| 分节 1 大包不被回溯到非普货档 | §2 回溯未截断陷阱 |
| `小包非普货计费` 不产生 `general` 类别 | 类别判定陷阱 |
| 验算样本：阿尔巴尼亚 100g → 39.67 元；大包首重/续重阶梯 | 公式错 |
| 版式族：1~3 行表头各自能解析 | 「表头行数写死 3 行」回归 |
| `Item 服务费` 认成挂号费、`minChargeG` 带出 10g、档位退化检查 | 叶子同义词与最低计费重量漏读 |
| 行式分档表整节拒绝 | 把"该档总价"当"每 KG 费率"（差两个数量级） |
| 非人民币线路整表拒算且 `reason` 含「汇率」，与「无可用运价」**文案分开** | 美元价按人民币算 |
| `any` 类别排最后、强制类别可兜底命中 | 不分品类表被强制查询判成无价 |
| `pluginTriage` 既有动态守卫 + `shipping-rate` 反向守卫 | 红线 23 与"源码被 .gitignore 吞掉" |
| `decidePermission` 真实判定：clipboard/storage/db 域 | 声明写法与权限门口径不一致 |
| 岛内不得 `eval` / `new Function` / `import 'xlsx'` | CSP 边界 |
| 运价表载荷节点数 < 预算上限 | `db.call` 被预算拦 |

   - **订单原始行**：新通道 `order-shipping-rows`（`oi_orders` 最小投影，只读）。
   - **逐单计价**：`quoteOrders(table, rows)` 复用 `pickCard`/`quotableRefusal`/`computeFee`；拒算分五类并**逐行携带 `reasonClass`**（noWeight / noCountry / unknownCountry / noPrice / refused）。⚠️ **数量恒按 1 件/行**（多产品订单拆行后每行仍带原始「数量」列值，用它会 3×3 错算；合并计费留待 UI 选择）。
