## 1. 产品概述

### 核心功能

| 功能 | 说明 |
|------|------|
| **导入 Excel** | 支持按钮选择、拖拽导入、启动自动加载三种方式 |
| **智能解析** | 自动识别表头、去除空行、去重列名 |
| **模板替换** | 使用 `{{列名}}` 占位符批量生成文本 |
| **一键复制** | 替换结果直接写入系统剪贴板 |
| **状态跟踪** | 自动标记已使用的记录并排序 |
| **字段处理规则** | 对已有字段进行日期偏移、模板拼接、数值运算、自定义脚本，生成衍生字段 |
| **多模板管理** | 多个模板切换、编辑、导入导出 |
| **撤销/重置** | 误操作可撤销，一键重置所有状态 |


## 2. 安装与启动

### 系统要求

| 平台 | 支持版本 |
|------|----------|
| macOS | Apple Silicon (arm64) — macOS 11+ |
| Windows | x64 — Windows 10+ |

### 安装方式

根据您的操作系统选择对应的安装包：

#### macOS 安装

提供两种格式，任选其一：

| 文件 | 说明 |
|------|------|
| `SellerKit-1.0.0-mac-arm64.dmg` | 磁盘映像安装包（推荐） |
| `SellerKit-1.0.0-mac-arm64.zip` | 压缩包（解压即用） |

**DMG 安装步骤**：
1. 双击打开 `.dmg` 文件
2. 将 `SellerKit` 拖入 `Applications` 文件夹
3. 首次打开时，如果提示"无法验证开发者"，请**右键点击应用 → 打开**

**ZIP 安装步骤**：
1. 解压 `.zip` 文件
2. 将 `SellerKit.app` 移动到 `Applications` 文件夹
3. 首次打开方式同上

#### Windows 安装

| 文件 | 说明 |
|------|------|
| `SellerKit-1.0.0-win-x64.exe` | NSIS 安装包 |

**安装步骤**：
1. 双击运行 `.exe` 文件
2. 选择安装目录（可自定义）
3. 安装完成后，桌面和开始菜单会创建快捷方式

## 3. 快速入门

### 3.1 准备数据

准备一个 Excel 文件（`.xlsx` 格式），第一行为列名，后续行为数据：

| 姓名 | 手机号 | 套餐 | 开通时间 |
|------|--------|------|----------|
| 张三 | 13800138000 | 24 Hours | 2025-01-15 10:00 |
| 李四 | 13900139000 | 7 Days | 2025-02-01 08:30 |

### 3.2 准备模板

创建一个文本文件（如 `模板.txt`），使用 `{{列名}}` 作为占位符：

```
尊敬的{{姓名}}用户：
您购买的{{套餐}}套餐已开通，到期时间为{{到期时间}}。
客服电话：{{手机号}}
```

### 3.3 基本流程

```
① 导入Excel → ② 配置模板 → ③ 点击记录 → ④ 复制到剪贴板 → ⑤ 粘贴使用
```

1. 点击工具栏 **导入** 按钮，选择 Excel 文件
2. 点击工具栏 **工具 → 模板配置**，导入模板文件
3. 在左侧列表中**点击**一条记录，右侧预览替换结果
4. 点击 **复制并标记已使用**，内容写入剪贴板
5. 在目标应用中 **粘贴(Ctrl+V)** 使用
6. 该记录自动移到底部，标记为已使用

## 5. Excel 数据导入

### 5.1 三种导入方式

#### 方式一：按钮导入
点击工具栏的 **导入** 按钮（📥），在弹出的文件对话框中选择 `.xlsx` 文件。

#### 方式二：拖拽导入
将 `.xlsx` 文件直接拖入应用左侧区域。拖入时区域会高亮显示边框。

> ⚠️ 仅支持 `.xlsx` 和 `.xls` 格式，拖入其他类型文件会提示错误。

#### 方式三：自动加载
启动应用时，如果上次关闭前有正在编辑的 Excel 文件且文件仍然存在，应用会自动加载该文件并恢复所有记录状态。

### 5.2 智能解析逻辑

导入 Excel 时，应用会自动进行以下处理：

| 处理步骤 | 说明 |
|----------|------|
| 读取第一个工作表 | 仅处理第1个 Sheet，多 Sheet 仅读取第一个 |
| 自动定位表头 | 跳过文件开头的空行，第一个非空行作为列名 |
| 去除尾部空行 | 数据末尾的空白行自动跳过 |
| 重复列名去重 | 相同列名自动加 `_1`、`_2` 后缀区分 |
| 保留已有状态 | 导入同一文件且行数相同时，保留 `used` 和 `order` 状态 |
| 规则变更检测 | 如果字段处理规则有变更，重新计算所有衍生字段 |

## 6. 记录列表操作

### 记录状态

每条记录有三种状态：

| 状态 | 显示效果 | 说明 |
|------|----------|------|
| **未使用** | 正常显示，左侧灰色圆圈图标 | 可点击复制并标记 |
| **已使用** | 降低透明度 + 文字删除线，左侧绿色勾号图标 | 点击仅复制，不改变状态 |
| **选中** | 蓝色背景 + 蓝色左边框 | 右侧显示预览内容 |

### 筛选模式

工具栏筛选按钮组：

| 模式 | 说明 |
|------|------|
| **全部** | 显示所有记录 |
| **未使用** | 仅显示未使用的记录 |
| **已使用** | 仅显示已使用的记录 |

按钮上的数字显示对应状态的数量。

### 搜索

在搜索框输入关键词，列表会实时过滤出任意字段包含关键词的记录。搜索不区分大小写。

### 列显示

点击工具栏的 **齿轮图标(⚙)**，弹出列选择菜单：
- 勾选/取消勾选要显示的列
- **衍生字段**显示为紫色并标注"衍生"标签
- 提供"全选"和"默认"快捷按钮
- 默认显示前两个原始列

### 排序规则

- **未使用记录**：按原始行号升序排列（1, 2, 3...）
- **已使用记录**：按使用顺序排列在末尾（从10000开始递增）
- 列表中未使用的记录始终排在已使用之前

```

```

**默认模板**：首次使用时，应用自带一个默认模板，内容为：

```
http://{{domain}}.beuaya.com/get.php?username={{Username}}&password={{Password}}&type=m3u_plus&output=mpegts

👤 Username: {{Username}}
🔑 Password: {{Password}}
🔗 DNS (URL): http://{{DNS}}
📺 Samsung & LG DNS (IPTV Smarters): http://{{domain}}.yufengsmart.com
📦 Package: {{Package}}
📅 Expiry Date: {{Package}}
```

其中 `{{domain}}` 是默认的字段处理规则生成的**衍生字段**（见下一节），会自动从 `DNS` 字段中提取域名前缀。

**智能提示**：在编辑区输入 `{{` 时，自动弹出可用列名列表（包含原始字段和衍生字段），选择后自动补全。**缺失字段**：如果模板中的占位符在数据中找不到对应值，预览中会用红色标记 `[字段缺失: xxx]`。

## 8. 字段处理规则

字段处理规则允许你对已有字段进行计算或转换，自动生成新的**衍生字段**。衍生字段可以像原始字段一样在列表展示、搜索匹配和模板占位符中使用。

### 打开规则管理器

点击工具栏 **工具 → 字段规则**，打开右侧抽屉面板。

### 面板布局

```
┌─────────────────────────────────────────────────┐
│  字段规则配置                    [立即应用] ✕     │
├──────────────┬──────────────────────────────────┤
│  规则列表     │  编辑区                          │
│              │                                  │
│  🔵 到期时间  │  规则名称: [计算到期时间____]    │
│  🔴 完整地址  │  目标字段: [到期时间________]    │
│  🟢 总价     │  处理类型: [日期偏移 ▼]          │
│              │                                  │
│              │  ── 日期偏移配置 ──              │
│  + 新建规则   │  源日期字段: [开通时间 ▼]        │
│              │  时长/套餐: [套餐 ▼]             │
│              │  输出格式: [YYYY-MM-DD HH:mm]    │
│              │                                  │
│              │  [保存规则] [删除规则]            │
│              │  3个原始字段 · 1个衍生字段        │
└──────────────┴──────────────────────────────────┘
```

### 规则列表

左侧显示所有规则，每条规则包含：
- **启用开关**：切换规则是否生效
- **规则名称**：用户自定义
- **类型标签**：日期偏移 / 模板拼接 / 数值运算 / 自定义JS（不同颜色区分）
- **序号**：执行顺序（数字越小越先执行）

### 四种规则类型

#### 类型一：日期偏移（dateOffset）

对日期字段加上指定的时长，生成新的日期字段。

| 配置项 | 说明 | 示例 |
|--------|------|------|
| **源日期字段** | 起始日期所在的列 | `开通时间` |
| **时长/套餐字段** | 包含时长的列 | `套餐`（值如 "24 Hours"） |
| **输出格式** | 结果日期格式 | `YYYY-MM-DD HH:mm` |

**支持的时间单位**：Hours / Days / Weeks / Months（也支持 hr、h、d、w 等缩写）

**示例**：
```
源日期: "2025-01-15 10:00"
套餐:   "24 Hours"
结果:   "2025-01-16 10:00"
```

#### 类型二：模板拼接（template）

使用 `{{字段名}}` 占位符拼接多个字段的值，生成新字段。

| 配置项 | 说明 | 示例 |
|--------|------|------|
| **拼接模板** | 包含占位符的模板文本 | `{{姓名}}-{{手机号}}` |

模板下方的按钮可快速插入字段名到光标位置。

**示例**：
```
模板: "{{省份}}{{城市}}{{区县}}{{详细地址}}"
结果: "广东省深圳市南山区科技园"
```

#### 类型三：数值运算（math）

对数值字段进行四则运算，支持 `+ - * /` 和括号 `()`。

| 配置项 | 说明 | 示例 |
|--------|------|------|
| **运算表达式** | 使用 `${字段名}` 引用字段 | `${单价} * ${数量}` |

表达式支持：
- `${单价}` — 引用字段值（自动提取数字部分）
- `+ - * /` — 四则运算
- `( )` — 控制运算优先级
- 直接数字，如 `* 1.2`（加20%）

选中一条记录后，表达式下方会显示**实时预览**。

**安全说明**：运算引擎使用自研解析器（递归下降），**不使用 `eval()`**，确保安全性。

#### 类型四：自定义表达式（jsExpression）

使用 JavaScript 表达式自由处理字段值。

| 配置项 | 说明 | 示例 |
|--------|------|------|
| **代码** | JS 表达式 | `fields["DNS"].split('.').slice(0, 1)[0]` |

**默认规则**：首次使用时，应用自带一条默认的 `jsExpression` 规则"域名解析"，用于从 DNS 字段提取域名前缀：

```
输入 DNS = "example.beuaya.com"
代码: fields["DNS"].split('.').slice(0, 1)[0]
输出 domain = "example"
```

> 该规则生成 `domain` 衍生字段，可在模板中用 `{{domain}}` 引用。默认模板已使用此衍生字段。

**使用规则**：
- 通过 `fields["字段名"]` 访问字段值
- 表达式需要返回一个值（字符串或数字）
- 自动 `toString()` 转为字符串

**安全说明**：代码在 `"use strict"` 模式下运行，`fields` 对象被冻结不可修改，防止污染全局作用域。

### 应用规则

规则配置完成后，通过以下方式触发执行：

| 触发方式 | 说明 |
|----------|------|
| **自动执行** | 导入 Excel 时自动执行所有启用的规则 |
| **立即应用** | 规则管理面板顶部的"立即应用"按钮，手动重新执行 |
| **重导入** | 如果规则有变更，重新导入同一文件时会重新计算 |

### 规则持久化

所有规则配置（名称、类型、参数、启用状态、执行顺序）自动保存到 `electron-store`，下次启动自动恢复。

## 9. 列显示控制

点击工具栏的 **齿轮图标(⚙)**，打开列显示选择器：

- **所有可用列**：按 `列名` 显示，原始字段灰色，衍生字段紫色并标注"衍生"
- **勾选/取消**：控制哪些列在列表中显示
- **全选**：显示所有列（慎用，字段过多时列表可能拥挤）
- **默认**：仅显示前两个原始列

**默认行为**：首次导入数据时，自动显示前两个原始列。衍生字段不会自动显示，需要手动勾选。

## 10. 预览与复制

### 预览面板（右侧）

选中一条记录后，右侧显示：

| 区域 | 内容 |
|------|------|
| **内容预览** | 模板替换后的完整文本，蓝色=成功替换，红色=字段缺失 |
| **字段详情** | 可折叠面板，列出该记录所有字段的键值对 |
| **状态标签** | 右上角显示"已使用"（绿色）或"未使用"（灰色） |

### 复制操作

| 操作方式 | 触发 | 效果 |
|----------|------|------|
| **点击预览面板按钮** | 点击"复制并标记已使用"或"仅复制" | 写入剪贴板 |
| **双击记录项** | 双击左侧列表中的记录 | 写入剪贴板 + 标记 |
| **回车键** | 选中记录后按 Enter | 写入剪贴板 + 标记 |

**状态变化**：
- **未使用记录**：复制后 → 标记为已使用 → 移动到底部 → 入撤销栈
- **已使用记录**：复制后 → 仅复制，状态不变

## 12. 数据持久化

SellerKit 会自动保存以下状态到本地存储：

| 数据 | 说明 |
|------|------|
| **最近文件路径** | 上次导入的 Excel 路径，启动时自动加载 |
| **记录状态** | 每条记录的 `used` 和 `order` 状态 |
| **模板配置** | 所有模板的名称、文件路径、内容快照 |
| **当前模板** | 激活的模板 ID |
| **字段规则** | 所有处理规则的完整配置 |
| **可见列设置** | 用户选择的显示列 |

**保存机制**：
- 任何数据变更后自动触发保存
- 500ms 防抖（debounce），避免频繁写入
- 使用 `electron-store` 优先，自动降级到 JSON 文件

## 13. 常见问题

### Q: 支持哪些 Excel 格式？
仅支持 `.xlsx` 和 `.xls` 格式。不支持 `.csv`。

### Q: 为什么导入后有的列没有显示？
新导入的数据默认只显示前两个列。点击工具栏齿轮图标 ⚙ 手动勾选要显示的列。

### Q: 模板里的字段显示红色"字段缺失"？
模板中使用了 Excel 数据中没有的列名。检查模板中的 `{{字段名}}` 是否与 Excel 列名完全一致（包括空格）。

### Q: 已经使用过的记录可以重新变成未使用吗？
可以。点击工具栏的 **重置** 按钮，将所有记录恢复为未使用状态。已撤销的操作也可以通过 **撤销(Ctrl+Z)** 逐个还原。

### Q: 为什么"立即应用"按钮没有效果？
"立即应用"只对当前已导入的数据生效。如果没有导入数据，或所有规则都已执行过且无变更，则不会有可见变化。

### Q: 字段规则的执行顺序重要吗？
重要。规则按序号升序执行，后执行的规则可以使用先执行的规则生成的衍生字段。例如：规则1生成"完整地址"，规则2可用 `{{完整地址}}` 做模板拼接。

### Q: 修改规则后需要重新导入 Excel 吗？
不需要。点击规则管理器顶部的 **立即应用** 按钮即可对当前数据重新执行所有规则。

### Q: 导出文件会覆盖原始 Excel 吗？
不会。SellerKit 是只读工具，不会修改原始 Excel 文件。模板文件会在保存时写入，但原始 Excel 数据绝对不会被修改。

### Q: macOS 上打开应用闪退？
应用未经过 Apple 签名。首次打开时需要右键 → 打开，或在"系统设置 → 隐私与安全性"中允许运行。打包后已内置修复脚本自动处理相关兼容性问题。

### Q: 数据存储在什么位置？
使用 `electron-store`，数据文件位于系统用户数据目录（macOS: `~/Library/Application Support/seller-kit/config.json`）。

### Q: 可以清空所有数据重新开始吗？
可以删除存储文件，或手动重置所有状态（点击"重置"按钮），或删除所有模板后重新导入。
