# 「货与成本」产品列表瘦身：撤一列时真正难的是"证明能力没丢"

**场景**：用户两条口径 —— ①「产品列表不展示 SKU、进价」，且**款式名现在展示不完全**；
②「展开页中的 SKU 也去掉」，样式再顺一遍。（2026-10-10）

## 结论（下次改这一页先看这五条）

1. **"展示不全"是两半问题，只做一半不会好**：
   撤列（腾宽度）+ **款名自己折行**。折行必须落在**里层 `span`** 上（`.gd-pane__name-text`），
   因为 `td` 得保持 `table-cell` —— 直接在 `td` 上写 `display:-webkit-box` 会让那一格**脱离表格布局**。
   上限两行、`title` 给全文。
2. **撤列必须逐条回答"那件事现在去哪做"**，否则就是静默降级（本仓 2026-10-08 记过的现行犯）：

   | 撤掉的 | 留下的入口 | 谁在守 |
   | --- | --- | --- |
   | 主表「缺克重」列 | 工具栏「问题件 › 缺克重」筛选 | `filter-issue`（既有 + "唯一入口"那条） |
   | 主表「进价」列 | 同页「进价」页签（含"还没维护进价的款"清单） | `cost-tab` 步 |
   | 展开区 SKU 清单 | 「编辑」抽屉（颜色 × 尺码 + 逐行克重） | `weight-save-in-drawer` 步 |

   ⭐ 判断顺序：**先问"这个数字还有没有别的界面入口"**，有才撤；撤的同时把反向守卫写上
   （"它不在了"也要钉住，加回来就红）。
3. ⚠️ **"临时开关 + 页级刷新"造/复位夹具，会污染别人的绝对计数**：
   为验长款名，一度写成"打开开关 → 点刷新 → 断言 → 关开关 → 再刷新"，
   结果**每次页级刷新右栏都会重新合批取图** ⇒ 队列那条"缩略图只合批取 **1** 次"实测变成 **3**
   （红的却是队列断言，排查方向整个反过来）。正解：**把长款名做成常驻夹具**（S1 的名字本身）。
   这与 2026-10-08 那条"绝对计数会被同通道其它调用污染"同源，**这次的污染源是我自己的夹具手法**。
4. ⚠️ **夹具必须能造出"放不下"，否则断言恒绿**：短款名（`款一`）在两行内怎么排都放得下 ⇒
   `scrollHeight <= clientHeight` 恒真。夹具里 S1 现在是 **24 字**长名（实测 314px 宽，
   1440 视口下款名列只有 231px ⇒ 必然折两行）。
   同理，**里层盒的 `clientHeight > 0` 必须写进判据**：退回单行省略号时它是 `display:inline`，
   `clientHeight/scrollHeight` 是 **0/0**，而 `0 <= 0 + 1` 恒真 —— 实测变异时它照样绿。
5. **回退形态（`GOODS_LAYOUT='tabs'`）不动**：`ProductListView` / `SkuMappingView` 的契约是
   "与重构前逐字一致，回退 = 改一个常量"。它的列组成现在与 workbench 不同，这是回退路径的应有状态。

## 取证

- 门禁：`tsc -p tsconfig.electron.json` ✅ · `vue-tsc --noEmit` ✅ · `verify` ✅（IPC 契约零改动）·
  `verify:docs` ✅ · `build` ✅ · `vitest run` **644 passed** ✅ · `goods:ui` **三遍 ALL PASS**。
- 计数：`npm run goods:ui > /tmp/x.log` 再数 `^PASS ` ⇒ **242 = 全量 220 + 默认窗口可达性 11 + 窄视口 11**
  （本次全量 +2：撤 3 条、加 5 条）。⚠️ baseline 原记的「227 = 205+11+11」与工作区实测对不上，
  已在 baseline 里标注**口径更正（第 3 次）**：同日那批「进价」页断言没被算进那 205。
- **变异复核（逐条确认变红，改完都 rebuild 过）**：
  1. 款名退回"单行省略号"（`max-width:0` + nowrap + ellipsis，里层 span 改回 `inline`）
     ⇒ 两条可读 FAIL：`长款名横向不溢出 w=314/231` · `长款名最多两行 h=0/0`。
  2. 把 `SKU` 列加回主表（th + td）⇒ 三条可读 FAIL：
     `主表不再有 SKU 数/缺克重/进价三列 sku=true` · `空态 colspan=5 表头=6` · `认款动作条 relate=383/467`。
     （后两条是"顺带被守住"的既有断言：撤列时 `gdColspan` 忘了改、以及列一多布局就变窄，都能被看见。）
- 实测值（1440 全量那遍）：左栏 476.8px；款名字格 `clientWidth=231 / scrollWidth=231`、
  折行盒 `clientHeight=scrollHeight=35`（= 两行）。
- `node --check` 的两个盲区本轮又各撞一次（都当场抓到，未造成假绿）：
  ① 外层模板串注释里带反引号 ⇒ 模板串提前闭合；② **注入脚本内部**的注释带反引号 ⇒ `node --check` 也报，
  但要按"抠出注入脚本单独 check"的习惯看，才不会把报错读到外层去。
