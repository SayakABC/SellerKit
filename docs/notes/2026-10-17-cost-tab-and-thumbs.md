# 「成本」页改名 + 款级进价列表改版（加图片列、去生效日/来源列）

**结论**（2026-10-17 深夜，用户口径「成本与费率修改为成本，其中款级进价列表增加图片，去除生效日、来源展示，要注意样式」）

两件事，都只动**呈现层**：

| # | 改动 | 范围 |
| - | ---- | ---- |
| ① | 页签名「成本与费率」→「成本」 | `MasterDataView` 的 `KINDS` + 全部用户可见引用 |
| ② | 款级进价**主表**：加图片列；去「来源」「生效日」两列（8 列 → 7 列） | `CostPane.vue` |

**区间明细表（展开区）两列都保留**：那边生效日是行的主键、来源决定它能不能删
（拿货对账的行不给删），去了这两列，"哪条在生效 / 哪条能删"就读不出来。
用户说的"列表"指主表（面板标题就叫「款级进价」），明细表是它的展开细节。

## ① 改名：只动呈现层

- `KINDS` 里 `cost` 的 `name` 改「成本」。**`store.mainTab` 的七个值与跨模块 action 的
  字符串协议一个没改** ⇒ 老用户本地偏好、算钱页「去维护」的 `action=cost` 全部照旧。
- 用户可见引用同步：`order-cost` 数据基础区的三处提示文案（"手工录在「基础数据」的
  「成本」里"…）。
- `tests/uxEntryNames.spec.ts` 的豁免键 `成本与费率` → `成本`。旧名是**悬空入口名**：
  豁免表里没有它，文案里再出现就直接红（这正是该守卫的用途）。

## ② 主表改版：为什么是这张表、为什么只改这张表

**加图片**：认款靠肉眼比图 —— 款编码是内部码、款名常常重名或空缺，而队列 / 选款弹层
本来就有图，只有这张表没有。数据链路：`productList` 行上现成的 `imagePath` →
`ipc.orderImageThumbBatch`（**core 里那个带拆批的包装**，不是裸 `ipc`）→ `Map<款编码, dataUrl>`。

**去两列**：来源与生效日回答"这条价怎么来的、从哪天起"，是**历史细节**；主表要回答的是
"这款现在多少钱、有几段价"。细节不放逐条摊开 —— 展开区里有全的。附带好处：让出表宽给图列。

## 三条实现约束

1. **取图只问表里有的款**。产品库翻页拉全量（上限 2 万款），而表通常只有几十行 ——
   遍历产品库取图是白取上万张。`loadThumbs()` 先用 `costRows` 的款编码做集合，再过 `products`。
2. **必须走 core 的拆批包装**（`ipc.orderImageThumbBatch`，`src/core/services/ipc.ts`）：
   主进程 `THUMB_BATCH_MAX = 40` 是**硬截断**（`payload.items.slice(0, 40)`），
   自己按原长度取值会让第 41 张起的图**静默变空占位**（不报错、只是没图）。
3. **图列必须给定宽**（62px = 40 图 + 2×10 padding + 边）：`table-layout:auto` 下不给宽度的
   列会被内容（宽图）撑着走，款名那条弹性列就得让位 —— 而列宽选择器都写在 td/th 上，
   **撑开是静默的**（几何取证才看得出来）。图与空占位的居中也要两条路都给：
   `img` 是 `display:block`（吃 `margin:auto`），占位 `span` 是 `inline-block`（只认 `text-align`）。

## 守卫怎么翻面

- **锚点随列走**：`cost-source` 撤掉（锚点是给列用的，列没了锚点也没了）。只删列不删断言的
  话，按旧名定位的东西**静默点空** —— 点了没反应，最难查。
- **`master-data:ui` 新增五条**：主表无来源/生效日列（表头 + 锚点双查）、主表七列、
  S1 渲染出 data: 缩略图、取图只问表里有的款、空态行 colspan 与列数一致。
- **夹具加 S3**（有图、**无成本**）：它是"取图范围"这条判据的**区分度来源** ——
  没有它，"遍历整个产品库取图"与"只取表里有的款"产出同一批调用，断言恒绿。
  反例就在首跑里：最初还要求"没有任何调用含 S3"，但货品档案工作台列的是**全部款**，
  它取 `[S1,S3]` 是正该发生的 ⇒ 判据改成"存在一次只含 `[S1]` 的调用"。
- **`shopAccountsIntake` 新增结构回归例**：主表 thead 有图列 / 无两列、明细表两列都保留、
  colspan 与列数一致、缩略图走拆批包装。⚠️ 明细表**嵌在主表 tbody 里**（展开行内），
  按整表切分会把明细的 `<th>` 算进主表 ⇒ 两边都只取各自的 `<thead>`。
- **变异验证**（各 88 PASS / 1 FAIL，其余不受）：
  取图改遍历全库 ⇒ 正好「取图只问表里有的款」红；`v-if` 改恒假 ⇒ 正好「S1 渲染出主图缩略图」红。

## ⭐⭐ 踩坑：模板串里的转义会被求值（`node --check` 查不出来）

首跑 `master-data:ui` 直接"没抓到 #smoke-result"。排查链路：注入脚本单独抽出来
`node --check` **通过**、页面 0 字节。真正原因：断言里用正则 `/^data:image\//` 判前缀，
写在模板串（`` ` ``）里 `\/` 被求值成 `/`，浏览器拿到 `/^data:image//` —— **语法错，
整段断言脚本都不跑**。而 `node --check` 查的是外层 .mjs 文件，模板串在它眼里只是个字符串。

这与已知的"注释里不能有反引号"同族：**模板串不是原文传递，转义与插值都会发生**。
判据只能实跑；要写正则就绕开需要转义的字符（本例改用 `indexOf(...) === 0`）。
自检方法：把模板串按 `\\ → \` 求值后再 `node --check` 一遍。
