## §1 真机实证清单（每条带复现路径与根因）

### B1 · 两栏口径分裂（缓存 bug）
- **复现**：全新款（无映射）→ 展开左栏行（「已关联商品 0 个」）→ 右栏认款成功 → 重新展开左栏行仍写 0 → 点「刷新」/收起再展开仍 0 → `Page.reload` 后正确显示「已关联商品 1 个」。
- **根因**：`ProductPane.vue` 的 `loadLinks`（≈`:626`）首次展开拉取并置位，此后**任何重展开都不再重拉**；认款链路（`useSkuPool`）不知道通知左栏。
- **严重**：用户刚做完"大事"（认款）立刻看到两个矛盾数字——对不会电脑的人，这不叫 bug，叫"这软件靠不住"。

### B2 · 「显示更多」假动作
- **复现**：「已建立映射」页签点「显示更多」→ 计数与行数不变；切回队列页签复测同样不变。
- **根因**：`useSkuPool.ts` 的 `shown` 分页判据 `groups > shown` 在"已认好的不再列"口径下**恒真**。
- **严重**：本仓已有结论"**假动作**"的现行犯——按钮存在、可点、点了没反应也不解释。

### B3 · 窄形态（<1180px）空态溢出 + 遮挡
- **复现**：视口 900×800：左栏高 ≈303px，空态按钮落 y≈474，容器底 ≈441 → 溢出；命中检测被上方工具栏遮挡，`click()` 无效。全新 userData 启动（窗口 871px 宽）左栏空态只剩一个图标。
- **根因**：堆叠布局没给左栏空态内容让位，超出时 `overflow` 裁掉，后续栏工具栏叠在其上。
- **严重**：**全新安装默认窗口就落在这个断点以下**——"新手第一屏按钮点不到"是第一印象。

### B4 · 宽形态 1200×800 队列溢出（默认窗口）
- **复现**：默认窗口（1200×800）右栏队列表超出容器右界；行内「对比」按钮命中 = `COVERED_BY` 且 x 右缘 > 视口宽；「操作」列表头被裁一半。
- **根因**：S2 列裁剪后 7 列在 1200 减侧边栏后仍放不下，表格无横向滚动兜底。
- **严重**：1200×800 就是默认窗口——S3 的"对比"动线在最常见尺寸下不可达。

### D1 · 店铺未归一死锁（真机复现）
- **复现**：删一条 `sk_name_map`（七店仍在 `oi_orders`）→ 重启 → 右栏提示条**纯文本长句，零可点元素**；受阻行「需先登记店铺」按钮 `disabled`，说明藏 `title`（触屏/不悬停的人永远看不到），且被裁出视口右界。
- **全新安装实测**：侧边栏只有 `今天/货与成本/便签/算钱/拣货` ——**没有「店铺账号管家**」（市场岛，默认包不含）。
- **结论**：静态报告"死锁"判断**成立且更糟**——不仅提示不可点，连目的地都不在软件里。

### W1–W4 · 包装层问题（真机复现，确认静态报告）
| # | 复现 | 与静态报告关系 |
|---|---|---|
| **W1** | 编辑抽屉只填款式名 → 「保存」灰、**无任何灰因** → 点 ✕ **静默丢弃零提示** | 坐实 UX-G3 |
| **W2** | 新建第一款即显示「`0 · 缺 0`」；全新首屏指标条全零铺满 | 坐实"全零不是正确表达" |
| **W3** | 展开左栏行后，直连按钮「关联到 123」出现在**右栏顶部**——视线正盯左栏 | 静态报告未提：动线终点不在焦点 |
| **W4** | 单行点「关联…」→ 弹层标题「**批量关联 1 项**」；确认键默认灰、不说明"要先勾选" | 坐实术语分裂 |

## §2 重构方案（分四步，每步独立可验收、可回退）

### R0 · 先修四个 bug（不动文案、不动形态）
| 修法 | 验收（`goods:ui` 断言） |
|---|---|
| **B1**：认款成功后通知左栏作废 `links` 缓存重拉；或 `loadLinks` 改"每次展开都拉" | 认款后不刷新页面，重新展开行 → 显示「已关联商品 1 个」 |
| **B2**：`showMore` 前置判据改"还有未列出的组"，没有更多时**不渲染按钮** | 列表列完时按钮不存在；有剩余时点击行数增加 |
| **B3**：堆叠布局给左栏 `min-height` 覆盖空态内容，或空态不依赖容器高度（居中+收紧内边距） | 900×800：空态按钮 `elementFromPoint` 命中自身 |
| **B4**：右栏队列容器加横向滚动，或按剩余宽度降列（保「店铺/商品ID/订单行/操作」四列） | 1200×800：「对比」「关联…」按钮 `elementFromPoint` 命中自身，表头完整 |

**守卫纪律（先于一切改码）**：`goods:ui` 现有断言按元素存在判定，拦不住 B3/B4。开工第一步给 runner 补 `assertReachable(act)` 助手（`elementFromPoint(中心点)` 命中自身或子孙），R0 的 4 组选择器改用它。

### R1 · 解死锁（D1）
1. 提示条改 **「1 家店铺未登记 → [去登记]」按钮形态**；岛已装→切到岛，未装→开插件中心定位「店铺账号管家」。
2. 「需先登记店铺」`disabled` 时的灰因从 `title` 提到**按钮旁常显小字**。
3. **待拍板 UX-G6**：根治 = 把"登记店铺"收进**内建**（只是"原店名→规范店名"映射，不需独立岛）——A 内建（建议）/ B 保持岛 + 引导安装。

### R2 · 包装层（继承静态报告 P0，真机已确认子集）
1. 术语词表全页统一（UX-G1，待拍板选词）；`批量关联 1 项` → 单项去"批量"（W4）。
2. 「`0 · 缺 0`」不渲染（W2）；指标条只在非零时列指标（含 `关联率 —`）。
3. 编辑抽屉统一保存模型（UX-G3）：建议全部即时保存，「取消」改「完成」；关闭有未保存改动时给确认（W1）。
4. 直连按钮就近视线（W3）：认款入口优先放**左栏展开区内**，右栏顶部直连保留为快捷方式。

### R3 · 首次动线（新手第一屏）
1. 空库一次性引导卡（UX-G4）：只在**零款 + 零订单**时出现，一张卡三步（① 导入订单 Excel → ② 确认店铺 → ③ 点一款认款），做完即消失；判据区分 `0` 与 `null`。
2. 应用内帮助入口（UX-G5）：页头「?」放 3 句话 + 30 秒步骤图；`docs/guides/USER_GUIDE.md` 重写或下线。

## §5 采集方法与局限
**做了**：`vite` dev server + `electron . --user-data-dir=<克隆>`（真实 userData 经 APFS clonefile 克隆；另全新空 userData）；CDP（`--remote-debugging-port`）驱动：全量控件 dump（`getBoundingClientRect` + `elementFromPoint` 命中检测）、真实点击走查（建档→展开行→认款全链）、视口覆盖 900px、窗口默认 1200×800 实测、人工摘除 `sk_name_map` 复现死锁、走查库 SQL 取证。截图留档：`01-default.png`（713px 瞬态）、`03-fresh.png`（全新首屏 871px）。
**局限**：① dev 模式未打包，打包版岛分发行为按 `modules.config.json`/`market-out/catalog.json` 静态认定；② 未跑 `npm run goods:ui` 基线（R0 开工前必须先跑）；③ 视口覆盖 ≠ 真实窗口缩放；④ 「显示更多」精确行数口径以代码判据为准，未逐帧留档。
